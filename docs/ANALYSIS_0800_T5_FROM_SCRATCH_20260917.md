## 三、全关占比对三类指标的传导（T5 实证）

### 1. `test F1` 随 `test关占比` 单调跌（`0%→42%→50%` : `0.93→0.65→0.60`）
- `B1 0关` → `F1 0.93`（`P 0.49 R1.0`，`SAE 0.03` 无除零）为 **全开段内测**，与 `infer 26%关` 错位 `26pct`
- `B1b 42%` → `0.65`（`P 0.49 R1.0` 但 `off_fp 183`），`B 50%` → `0.60`（`off 4天` 拉低均值 `86%天` 不达标）
- **结论**：`test` 关占比每 `+10pct` 约 `F1 -0.07`，`50/50` 评测才可比 `infer 26%`（`B1b 42%` 已近）

### 2. `val F1` 随 `val关占比` 同跌（`B1 12%→0.93` vs `B1b 37%→0.73`）
- `val 12%` 早停乐观（`ep38 val_loss 1.42` 偏晚），`val 37%` 回 `0.73` 可信，早停 `ep33→40` 正常化

### 3. `infer F1` 随 `训练关占比` 非单调（`B 57%→0.77` vs `B1b 42%→0.69` vs `LAG5 42%+lag→0.75`）
- `B 57%` 关先验重致 `proportional 0.77` 高于 `B1b 42%` 的 `0.69`（关多学关，`P 0.51` 低但 `R 0.99` 守）
- `LAG5` 同 `42%` 但 `R² +0.10` 反超至 `0.75`，证 **关占比非唯一瓶颈，时滞 > 关占比**
- `OFF8 40%→infer 0.67` 跌（删关至 `60%开` 使 `train 0.89→0.89` 跌，`infer fp 400→580` 涨）——**删关过头伤 `transformer` 边界学习**

### 4. `R²/SAE` 与 `test关占比` 解耦
- `B1 0关 R² 0.79` 虚高（全开 `R²` 天然高），`B1b 42% R² 0.42` 回落但 `infer R² 0.39→0.49` 仍低，`lag5` 抬 `0.39→0.49` 证时滞主导
- `SAE` 在 `全关天 Σy=0` 时 `÷0` 发散（`D-7`），`test 0关 SAE 0.03` 低假象 vs `B1b 0.36` 真值

## 四、T5 最优与推荐

- **分类**：`LAG5 0.750` > `B 0.77?` 实 `B` 为 `proportional`，`T5` 维度 `LAG5 0.750` 为 `T5` 峰（`B1b 0.691` Vertrag）
- **回归**：`LAG5 R² 0.496 SAE 0.032` 大幅胜 `B1b 0.391/0.220`
- **关占比**：`B1b 42%` 均摊已是最贴 `infer 26%` 的可信评测（`OFF8 40%` 未更优），**再删关不治 `T5`**

## 五、结论

**全关占比显著影响 `test`（`0%→42% F1 -0.27`），轻微影响 `infer`（`57%→42% F1 -0.08`），但 `LAG5` 时滞可覆盖**：

1. **评测可信度**：`test` 须含关 `2-3天 28-42%`（`B1b`）才可比 `infer 26%`，`0关` 不可信
2. **训练先验**：`train 65%→42%` 未直接转 `infer` 增益，需 `lag5` 叠加
3. **T5 推荐**：维持 `B1b 38天 + lag5 [5,1,2,3,4] + stratified_by_state`（`default/base_t5` 已合入），`test 0.70 R²0.28` 为新可信基线，`infer 0.75` 为当前天花板；`OFF8` 删关仅 `history` 有效，`T5` 勿删

*产物*：`B1b/LAG5/OFF8` 三档 `T5` `train 21/40/28 ep` + `infer 19天5关` + `audit` 全绿 + `threshold_sweep test 100峰0.689`。
